# Data: sieć komórkowa przy Wi-Fi/ADB i Tailscale
Branch feature/stable-signing-20261006 / PR #21 zależny od #20. Ostatni kod 1a5fb94fb80944b0410bc3ff69ff5ba11b0f578f, CI187 PASS227, stable APK118701. Naprawa causes/errno ukończona, nie jest naprawą dostępu do sieci.

Nowy dowód 2026-10-07: skrypt ADB na APK118501 potwierdził formularz1MB/VPN i kliknięcie startu, ale nie zapis wyniku. Telefon pokazał preflight „Brak dostępnego bezpośredniego połączenia komórkowego”; Wi-Fi utrzymuje wireless ADB i musi pozostać włączone. Użytkownik wstrzymał testy ADB. Nie zalecać wyłączenia Wi-Fi, nie uruchamiać nowych prób i nie utożsamiać kliknięcia z rozpoczęciem transferu. Instalacja118701 w tej konfiguracji nie jest potwierdzona.

Potwierdzona luka: prepare() wybiera z activeNetwork/allNetworks; nie wywołuje requestNetwork i nie utrzymuje żądania CELLULAR. Android może nie utrzymywać sieci bez aktywnego żądania. To możliwa przyczyna preflight, nie dowód źródła wcześniejszego RESPONSE35ms.

Cel następnego checkpointu: po świadomym starcie testu uzyskać i utrzymać NetworkRequest CELLULAR/INTERNET/NOT_VPN, bez process bind, zmiany Wi-Fi/VPN i fallbacku; ograniczone oczekiwanie i anulowanie; release callbacku na każdej ścieżce. Nie żądać sieci w formularzu ani dialogu. Normalne CHANGE_NETWORK_STATE wymagane przez API należy sprawdzić w manifest i dodać tylko do tego celu. Kryteria: regresje lifecycle/cancel/timeout/lost/race/no request-before-start/no HTTP on invalid network, CI PASS i stable APK. Tryb incremental. Ta tura: przegląd kodu/dokumentacji i aktualizacja planu, bez zmiany aplikacji ani nowego builda.
